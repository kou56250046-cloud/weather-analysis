# 実況「この先6時間」に降水量の棒と降水確率の線を足す

## 背景

`live-next-6h.md` で「この先6時間」を札で出したが、降水量と降水確率は札の中の小さな文字でしか読めない。
雨がいつ強まり、いつ上がるかを一目で追えるよう、6時間分を1枚のグラフにする（2026-09-19 ユーザー依頼）。

`live-next-6h.md` の非目標「降水グラフへの予報の重ね描き」は維持する。実測の10分値グラフには載せず、
予報だけの別グラフにするので、10分値と1時間値の単位が混ざらない。

## 設計

### データ

既存の `nextHours` が返す `fc`（`prcp` = 前1時間の降水量 mm、`pop` = 降水確率 %）をそのまま使う。取得は変えない。

### 置き場所と見出し

「この先6時間」パネルの札の列の下、リンクの上。小見出し「降水 1時間ごと（予報）」。
下にある実測の「降水の6時間」（10分ごと）と単位が違うことを見出しで示す。

### 座標（棒・点・目盛り・カーソルを同じ x に揃える）

- `frame` の `xDomain` を `[-0.5, n - 0.5]` にする（n = `fc.length`）。
  こうすると `f.x(i)` = `innerW × (i + 0.5) / n` となり、`bars` が棒を置く枠の中央と一致する
- 折れ線・点・目盛り・十字カーソルはすべて `f.x(i)` で置く
- 目盛りは各枠の時刻（`timeLabel(fc[i].at)`）。札の時刻と一致する
- `bars` には `tip` を渡さない。十字カーソルの札と二重に出るため

### 縦軸（二軸）

- **左軸 = 降水量 mm（棒）**。上限は `rainScaleMax(fc)` = `niceScale(0, max(数値の prcp, 1) × 1.15, 4)`。
  降っていなくても軸が潰れないよう最小 1mm。**グリッド線は左軸の目盛りからだけ引く**（既存の `yAxis`）
- **右軸 = 降水確率 %（線）**。0〜100 固定。目盛りの文字 0 / 25 / 50 / 75 / 100 と単位「%」を右端に出す。
  **グリッド線は引かない**
- 色: 棒と左軸の単位「mm」は `--series-1`、線・点・右軸の文字と「%」は `--series-3`
- 右の余白は 44（「100」と「%」が収まる幅）

### 0 と欠測（null）の描き分け

- `prcp` が 0 → 既存の `bars` どおり高さ 0.8px の細い線（0mm という値を示す）
- `prcp` が null → 棒を描かず、その枠の横軸の上に「—」を出す（降らないのではなく分からない）
- `pop` が null → その点を打たず、線はそこで切る（既存の `line` の挙動）
- 十字カーソルの札は既存の `fcTipFor`。null の項目は行ごと出さない（既存どおり）

### 出す条件

`prcp` か `pop` のどちらかが数値である枠が2つ以上あるときだけ出す。それ以外は札だけ。

### 注記

「棒はその時刻までの1時間の降水量。最初の棒の時間帯は、一部が下の実測と重なる。統計補正はしていない。」

## 受入条件

- [ ] 実況を開くと、札の下に `fc` の本数ぶんの枠が並ぶ。`prcp` が数値の枠には棒、`pop` が数値の枠には点があり、点は線でつながる
- [ ] 棒の中心・点・横軸の目盛り・十字カーソルの縦線が、どの枠でも同じ x に来る
- [ ] 横軸の目盛りの時刻が札の時刻と一致する
- [ ] 左軸の目盛りは棒と同じ色の「mm」、右軸は 0/25/50/75/100 で線と同じ色の「%」。グリッド線は mm の目盛りにだけ引かれている
- [ ] 全時間 0mm のとき、左軸は 0〜1.5mm で、棒は高さ 1px 未満の線だけになる
- [ ] `prcp` が null の枠は棒が無く、「—」が出る
- [ ] 数値のある枠が1つ以下のときはグラフが出ず、札だけになる
- [ ] 十字カーソルで各時刻の降水量・確率・気温・風が出る
- [ ] 実測の「降水の6時間」グラフは変わらない
- [ ] Open-Meteo を止めたときは今と同じく「この先の予報は取れなかった」だけが出る
- [ ] `node --test test/*.test.js` が通る

## 非目標

- 実測の降水グラフ（10分値）への予報の重ね描き（単位が違う。前回の非目標を維持）
- 6時間より先、15分刻み、降水量の予測区間（幅）
- 降水確率の統計補正。日別の確率にしか較正していないので、ここは Open-Meteo の値をそのまま出す
- 気温・風のグラフの変更、札の変更
- `chart-svg.js` の変更（右軸の汎用化を含む）。右軸と「—」は `live.js` の中で描く

## 触るファイル

- `public/assets/live.js` — `rainScaleMax(fc)` と `rainChart(fc)` を追加し、`nextPanel` から呼ぶ。
  `rainScaleMax`、出す条件を判定する `rainChartable(fc)`、検証用に `rainChart` を `export` に足す
- `test/live.test.js` — 次のテスト
  - `rainScaleMax`: 全 0 → max 1.5、全 null → 1.5、最大 0.4mm → 1.5、最大 2.3mm → 3、最大 4mm → 6
  - `rainChartable`: 数値の枠が 2 つ → true、1 つ → false、全 null → false、prcp だけ null で pop が数値 → true

## 検証方法

1. `node --test test/*.test.js`
2. `node scripts/serve.js` → 予報タブ →「現在の天気の詳細を取得する」で目視（Playwright で http 経由）。
   棒の中心と点の x 座標を DOM から取り出し、一致していることを数値で確かめる
3. `fc` の値を差し替えられないので、0 と null の描き分けはページ上で `rainChart` に作った `fc` を渡して描いて確かめる
   （Playwright の evaluate で live.js を import して呼ぶ）
4. Open-Meteo をブロックしてグラフが出ず文言だけになることを確認
